# JobHuntAssistant

Собирает вакансии с нескольких площадок (trudvsem, SuperJob, сохранённые страницы hh.ru), отсеивает и ранжирует их по профилям из `profiles.yaml` и выгружает топ в `~/Documents/JobHunt` для писем через нейросеть.

## Команды
- `python run.py --check` — какие источники готовы и почему остальные пропущены
- `python run.py` — дневная выгрузка; `--sources trudvsem`, `--profiles pos helpdesk`, `--top 20`
- `pytest` — тесты (без сети, на фикстурах в `tests/fixtures`)
- Скилл `job-letters` — сбор + письма по резюме в `letters.md`

## Устройство
- `jobhunt/sources/` — по файлу на площадку, общий интерфейс `Source` (`unavailable_reason`, `fetch`, `enrich`). Новый источник регистрируется в `jobhunt/sources/__init__.py`.
- `jobhunt/models.py` — общая модель `Vacancy`; `jobhunt/scoring.py` — фильтры и баллы; `jobhunt/pipeline.py` — сбор, дедупликация между площадками, топ-N; `jobhunt/export.py` — md/csv/трекер.
- Проект должен работать с любым одним готовым источником: неготовый источник пропускается с причиной, а не роняет запуск.

## Правила
- Репозиторий публичный. Не коммить `.env`, `profiles.local.yaml`, резюме, содержимое папки выгрузки и сырые ответы API (в них бывают ФИО и телефоны). Фикстуры — только обезличенные.
- hh.ru закрыл API для соискателей 15.12.2025: не добавляй запросы к api.hh.ru и не обходи защиту сайта. hh — только через страницы, сохранённые пользователем.
- Никаких автооткликов.
